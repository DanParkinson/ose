## Purpose

The default sender defines the email address used when Django generates outgoing email messages.

This provides a consistent sender identity across all authentication-related email workflows.

## Default Sender Role

When an email is generated, Django uses the configured default sender address as the email's sender.

The sender address appears in the email headers and identifies the source of the message.

The default sender is used unless a specific sender address is explicitly provided.

Current email workflows include:

```text
Email Verification
Password Reset
Account Reactivation
```

## Configuration

The platform uses Django's default sender configuration.

Example:

```py
DEFAULT_FROM_EMAIL = os.environ["DEFAULT_FROM_EMAIL"]
SERVER_EMAIL = DEFAULT_FROM_EMAIL
```

The value is provided through the production environment and is not stored directly in source control.

## Current Sender Strategy

The platform uses role-based email aliases rather than personal email addresses.

The current sender configuration uses:

```text
accounts@open-source-education.co.uk
```

for automated account-related communications.

Although all aliases currently route to the primary admin mailbox, separate aliases provide clearer ownership and allow responsibilities to be separated in the future.

## Development Behaviour

During local development, emails are written to the terminal using Django's console email backend.

The configured sender address is still included in the generated email output and can be inspected during testing.

This allows email workflows to be verified without sending real emails.

## Production Behaviour

In production, emails are sent through Google Workspace using the configured sender address.

Workflow:

```text
Django
        ↓
Google Workspace SMTP
        ↓
Recipient Inbox
```

Using a sender address associated with the project's domain helps improve:

```text
Email authenticity
Email deliverability
Platform branding
```

## Related Infrastructure

The default sender works together with:

```text
Primary Mailbox
Email Aliases
Google Workspace
SMTP Configuration
SPF
DKIM
DMARC
```

These systems ensure that emails generated by Django are sent using an authenticated sender identity associated with the platform's domain.
