## Purpose

The email backend defines how Django delivers email messages generated by the application.

The platform uses different email backends depending on the environment:

```text
Development → Console Backend
Production  → SMTP Backend
```

This allows authentication workflows to be developed and tested locally while supporting real email delivery in production.

## Email Backend Role

Django uses the `EMAIL_BACKEND` setting to determine how generated email messages are delivered.

Authentication-related features generate email messages which are then passed to the configured email backend.

Current email workflows include:

```text
Email Verification
Resend Verification Email
Password Reset
Account Reactivation
```

The email backend is responsible for delivery, while the authentication system is responsible for deciding when an email should be generated.

## Development Backend

During local development the platform uses Django's console email backend.

```py
EMAIL_BACKEND = "django.core.mail.backends.console.EmailBackend"
```

This backend does not send real emails.

Instead, generated emails are written directly to the Django terminal.

This allows authentication workflows to be developed and tested without requiring SMTP credentials or an external email provider.

### Console Email Output

When an email is generated during development, Django prints the complete message to the terminal.

The output includes:

```text
Subject
Sender
Recipient
Message Body
Verification Links
Reset Links
```

This allows links to be copied directly from the terminal during testing.

Example workflow:

```text
User Registers
        ↓
Verification Email Generated
        ↓
Email Printed To Terminal
        ↓
Verification Link Copied
        ↓
Frontend Verification Page Opened
        ↓
Verification Submitted
```

## Production Backend

In production the platform uses Django's SMTP backend.

```py
EMAIL_BACKEND = "django.core.mail.backends.smtp.EmailBackend"
```

Unlike the console backend, the SMTP backend sends real emails.

Django generates the email message and passes it to Google Workspace for delivery.

This backend is responsible for sending:

```text
Email Verification
Password Reset
Account Reactivation
```

to real users.

## Current Email Workflows

The email backend currently supports:

```text
Email Verification
Resend Verification Email
Password Reset
Account Reactivation
```

All email generation originates from the authentication system.

The email backend only determines how those messages are delivered.

## Backend Selection

The platform selects the appropriate email backend based on the environment.

Development:

```text
Console Email Backend
```

Production:

```text
SMTP Email Backend
```

This approach allows email functionality to be developed and tested locally without requiring a live email provider while still supporting real email delivery in production.

## Related Infrastructure

The production email backend works together with:

```text
Google Workspace
Primary Mailbox
Email Aliases
SMTP Configuration
SPF
DKIM
DMARC
```

Django generates the email, the configured backend handles delivery, and the surrounding email infrastructure ensures messages can be authenticated and delivered successfully.
