## Purpose

Email sending is the process by which generated email messages are prepared and passed to the configured email backend for delivery.

The email sending process acts as the bridge between application functionality and email delivery infrastructure.

## Email Sending Process

Email messages follow a standard workflow:

```text
Application Event
↓
Email Generated
↓
Template Rendered
↓
Email Backend Selected
↓
Message Delivered
```

The specific delivery mechanism depends on the configured email backend.

## Email Generation

Email messages are generated by application functionality when an email communication is required.

The email generation process determines:

```text
Recipient
Subject Template
Message Template
Template Variables
```

The email sending system itself does not determine when an email should be generated.

## Template Rendering

Before an email can be delivered, Django renders the selected email templates.

This process replaces any dynamic template variables with runtime values.

The rendered result becomes the final email message passed to the email backend.

## Backend Delivery

Once an email has been rendered, Django passes the completed message to the configured email backend.

The backend is responsible for:

```text
Message Delivery
Connection Management
Transport Configuration
Provider Communication
```

The sending process remains unchanged regardless of which backend is configured.

## Development Behaviour

During local development, generated emails are delivered through Django's console email backend.

```py
EMAIL_BACKEND = "django.core.mail.backends.console.EmailBackend"
```

This backend writes email content directly to the Django terminal rather than sending messages to a real inbox.

This allows email functionality to be developed and tested without requiring a production email service.

## Production Relationship

The email sending process remains the same across development and production environments.

The only difference is the configured email backend.

Development:

```text
Email Content → Console Backend → Terminal Output
```

Production:

```text
Email Content → SMTP Backend → Email Provider → Recipient Inbox
```

The application generates email messages in the same way regardless of the delivery infrastructure being used.
