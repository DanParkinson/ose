# Registration

## Purpose

Registration allows new users to create an account on the platform.

The registration system is designed around email-first authentication and minimal account complexity.

## Responsibilities

The registration system is responsible for:

```text
- Creating new user accounts
- Validating registration data
- Preventing duplicate email addresses
- Supporting frontend registration forms
- Integrating with the authentication system
```

## Registration Approach

The platform uses email-based registration.

Users register using:

```text
- Email Address
- Password
- Password Confirmation
```

Username-based registration is intentionally removed.

This keeps the registration process simple and consistent with the platform's email-first authentication approach.

## Validation

Registration data is validated before a user account is created.

The registration system checks:

```text
- Email address is provided
- Email address is unique
- Password is provided
- Password confirmation matches
- Password satisfies validation rules
```

If validation fails, errors are returned to the frontend.

## Duplicate Email Handling

The registration system prevents multiple accounts from using the same email address.

If a user attempts to register with an existing email address, the backend returns a validation error.

This ensures each email address represents a single account identity.

## Frontend Relationship

The frontend uses the registration system to:

```text
- Display the registration form
- Submit registration details
- Show validation errors
- Redirect or update UI after successful registration
```

The frontend does not create users directly.

All registration logic is handled by the backend.

## Authentication Integration

Registration is connected to the wider authentication system.

Once an account is created, the user can authenticate using:

```text
- Email Address
- Password
```

The registration system works alongside the platform's login, logout, and session management workflows.

## Design Principles

The registration system is designed around:

```text
- Email-first authentication
- Minimal required user data
- Predictable validation behaviour
- Frontend-compatible error responses
- Simple account creation
```

The goal is to keep registration clear, simple, and consistent with the rest of the authentication experience.
