# Frontend Authentication

## Purpose

Frontend authentication manages how the React application understands and responds to the user's authentication state.

It controls whether the user is treated as anonymous, authenticated, or authorised for staff-only areas.

## Core Responsibilities

The frontend authentication system is responsible for:

```text
- Storing the current user state
- Checking the current session on app load
- Exposing authentication actions
- Protecting frontend routes
- Controlling authentication-based UI rendering
```

## Main Parts

The frontend authentication system is built around:

```text
- AuthProvider
- AuthContext
- useAuth
- ProtectedRoute
- PublicRoute
- AdminRoute
- Axios credential handling
```

## AuthProvider

AuthProvider wraps the application and makes authentication state available globally.

It sits near the root of the application so that all routes and components can access authentication data.

## AuthContext

AuthContext stores the current authentication state.

It provides:

```text
- Current user
- Loading state
- Authentication actions
```

This prevents individual components from managing authentication state independently.

## useAuth

The useAuth hook provides a simple way for components to access authentication state and authentication actions.

Components use this hook instead of importing AuthContext directly.

## Route Protection

The application uses route wrapper components to control access to pages.

```text
ProtectedRoute = authenticated users only
PublicRoute    = unauthenticated users only
AdminRoute     = staff users only
```

These route wrappers use the current user state to decide whether to render a page or redirect the user.

## Axios Relationship

Frontend authentication depends on Axios being configured to send credentials with API requests.

This allows authentication cookies to be included automatically.

The frontend does not manually store or manage JWT tokens.

## Backend Relationship

The frontend manages authentication state and UI behaviour.

The backend remains responsible for:

```text
- Validating credentials
- Issuing authentication cookies
- Refreshing tokens
- Enforcing permissions
```

## Key Principle

```text
Frontend authentication controls user experience.

Backend authentication controls security.
```

The frontend can decide what to show, but the backend decides what the user is actually allowed to access.
