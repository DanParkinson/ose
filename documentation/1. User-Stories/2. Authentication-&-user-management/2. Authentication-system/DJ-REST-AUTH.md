## Purpose

DJ-Rest-Auth provides the authentication API layer for the platform.

It integrates Django Authentication, Django Allauth, and JWT authentication into a REST API that can be consumed by the React frontend.

The package provides common authentication functionality without requiring custom implementations for registration, login, logout, password management, and authenticated user retrieval.

## Authentication Responsibilities

DJ-Rest-Auth is responsible for:

```text
User Registration
User Login
User Logout
Current User Retrieval
Password Change
Password Reset
JWT Authentication Integration
```

The package acts as the primary authentication interface between the frontend and backend.

## JWT Authentication

The platform uses JWT-based authentication.

```py
"USE_JWT": True
```

JWT authentication replaces traditional token authentication and allows authenticated sessions to be maintained through secure cookies.

Authentication state is validated by the backend on every protected request.

## Authentication Cookies

The platform stores JWT tokens inside dedicated authentication cookies.

```py
"JWT_AUTH_COOKIE": "access"
"JWT_AUTH_REFRESH_COOKIE": "refresh"
```

The authentication system uses:

```text
access   → short-lived authentication token
refresh  → token renewal token
```

These cookies are automatically included with authenticated requests.

The frontend does not manually manage authentication tokens.

## HTTP Only Cookies

Authentication cookies are configured as HTTP-only.

```py
"JWT_AUTH_HTTPONLY": True
```

This prevents authentication cookies from being accessed through JavaScript.

Using HTTP-only cookies helps reduce exposure to cross-site scripting (XSS) attacks.

## Secure Cookie Configuration

Authentication cookie security changes depending on the environment.

```py
"JWT_AUTH_SECURE": JWT_AUTH_SECURE
"JWT_AUTH_SAMESITE": JWT_AUTH_SAMESITE
```

Development configuration:

```text
Secure = False
SameSite = Lax
```

Production configuration:

```text
Secure = True
SameSite = None
```

This allows local development over HTTP while enforcing HTTPS-only authentication cookies in production environments.

## Custom Authentication Serializers

The authentication system uses custom serializers to extend the default DJ-Rest-Auth behaviour.

```py
"REGISTER_SERIALIZER":
    "accounts.api.serializers.CustomRegisterSerializer"

"USER_DETAILS_SERIALIZER":
    "accounts.api.serializers.CustomUserDetailsSerializer"
```

These serializers provide support for:

```text
Email-based registration
Email validation
Custom authenticated user responses
```

while continuing to use DJ-Rest-Auth's authentication workflow.

## Password Management

The platform customises password change behaviour.

### Old Password Requirement

```py
"OLD_PASSWORD_FIELD_ENABLED": True
```

Users must provide their current password before changing it.

This provides an additional confirmation step when updating account credentials.

### Session Handling

```py
"LOGOUT_ON_PASSWORD_CHANGE": False
```

Changing a password does not automatically terminate the current authenticated session.

Users remain logged in after successfully updating their password.

## Password Reset Configuration

Password reset links generated by the backend point to the frontend password reset route.

```py
"PASSWORD_RESET_CONFIRM_URL":
    "reset-password/{uid}/{token}"
```

The generated URL contains:

```text
User Identifier (uid)
Password Reset Token
```

These values are later submitted back to the backend to validate and complete the password reset process.

## Frontend Relationship

The frontend communicates with authentication endpoints provided by DJ-Rest-Auth.

The frontend is responsible for:

```text
Displaying authentication forms
Submitting authentication requests
Managing authentication state
Protecting frontend routes
Displaying authentication errors
```

The backend remains responsible for:

```text
Credential validation
JWT generation
JWT validation
Authentication cookies
Password management
Authenticated user responses
Permission enforcement
```
